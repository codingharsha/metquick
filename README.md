# MetQuick

## Overview
MetQuick is a mentor–student platform focused on connecting students with mentors through sessions, messaging, community features, reviews, and dashboards.

## Current Status
- Frontend migration from client HTML prototypes to Next.js
- Backend integration planned later

## Tech Stack
- Next.js (App Router)
- React
- JavaScript
- CSS
- Git/GitHub

## Goals
- Clean architecture
- Reusable components
- Production-ready frontend
- Responsive UI
- Easy backend integration
